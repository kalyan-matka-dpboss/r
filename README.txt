# DPBOSS Telegram Lead-Generation Landing Page

A compact, mobile-first landing page inspired by the supplied DPBOSS screenshot:
- Peach/orange background
- Hot-pink DPBOSS accents
- Navy text
- Red separator-style details
- Telegram blue primary CTA
- Minimal content so the page fits on one mobile screen
- Hindi/Hinglish/simple English copy
- No external JS libraries

## Setup
1. Open `script.js`.
2. Replace:
   `https://t.me/YOUR_CHANNEL`
   with your actual Telegram channel URL.
3. Open `index.html` in a browser or upload all three files to your hosting.
